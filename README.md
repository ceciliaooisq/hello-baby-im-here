# Baby, I'm Here ♡

A tiny responsive girlfriend work companion. It works on phone and desktop and uses no backend.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `baby-im-here`).
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub to publish the site. The URL will look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Notes
- The site is responsive for mobile and desktop.
- It rotates through messages every 3 minutes and shuffles the main message pool without repeats until the pool is used.
- The three buttons show special hug, kiss, and stress-relief messages.
- The timer runs while the page is open. Browsers may pause timers in background tabs or when a phone locks; the next message may appear when the page is active again.
- This is a static site: no account, database, or API key is required.
